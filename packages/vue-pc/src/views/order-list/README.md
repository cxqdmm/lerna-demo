# 订单列表模块

## 功能概述

订单列表模块是一个基于 Vue 3 + Ant Design Vue + Pinia 的完整列表页面实现，包含搜索、分页、状态管理等功能。

## 文件结构

```
order-list/
├── index.vue              # 主入口页面
├── store.ts               # Pinia 状态管理
├── api.ts                 # API 接口定义
├── types.ts               # TypeScript 类型定义
├── components/
│   ├── SearchForm.vue     # 搜索表单组件
│   └── DataTable.vue      # 数据表格组件
└── README.md              # 说明文档
```

## 功能特性

### 1. 搜索功能

- 团订单号：支持精准搜索，默认为空查询全量
- 投保单位：支持模糊搜索，默认为空查询全量
- 商品名称：支持模糊搜索，默认为空查询全量
- 销售人员姓名：支持模糊搜索，默认为空查询全量
- 销售渠道：下拉框枚举值（寿渠、银行、产险、养老险、健康险直销）
- 产品经理：支持模糊搜索，默认为空查询全量
- 机构：支持模糊搜索，默认为空查询全量
- 状态：下拉框枚举值（进行中、待支付、已支付、已完成、关闭）

### 2. 按钮功能

- **查询**：如搜索框内容为空，点击查询则无响应
- **重置**：清空搜索框内容

### 3. 状态与操作关系（已实现交互功能）

| 状态   | 对应按钮           | 处理描述                             |
| ------ | ------------------ | ------------------------------------ |
| 进行中 | **详情**           | 点击跳转详情子页面                   |
|        | **清单上传**       | 点击弹出确认弹框，确认后模拟上传操作 |
|        | **关闭**           | 点击弹出危险操作确认弹框             |
|        | **分享**           | 点击弹出确认弹框，生成分享链接       |
| 待支付 | **详情**           | 点击跳转详情子页面                   |
|        | **关闭**           | 点击弹出危险操作确认弹框             |
|        | **下载缴费通知书** | 点击弹出确认弹框，生成并下载PDF文件  |
|        | **分享**           | 点击弹出确认弹框，生成分享链接       |
| 已支付 | **详情**           | 点击跳转详情子页面                   |
|        | **分享**           | 点击弹出确认弹框，生成分享链接       |
| 关闭   | **详情**           | 点击跳转详情子页面                   |
| 已完成 | **详情**           | 点击跳转详情子页面                   |

### 4. 交互功能详情

- **详情跳转**：使用Vue Router跳转到 `/order/detail/{id}` 路径
- **确认弹框**：使用Ant Design Vue的Modal.confirm组件
- **加载状态**：操作过程中显示加载动画
- **成功反馈**：操作完成后显示成功消息
- **错误处理**：操作失败时显示错误消息
- **数据刷新**：操作完成后自动刷新列表数据

## 技术实现

### 1. 技术栈

- **Vue 3** - 使用 Composition API
- **TypeScript** - 类型安全
- **Ant Design Vue** - UI 组件库
- **Pinia** - 状态管理（setup 语法）

### 2. 组件设计

- **模块化设计**：搜索表单和数据表格独立组件
- **响应式状态管理**：使用 Pinia setup 语法
- **TypeScript 支持**：完整的类型定义

### 3. 状态管理

使用 Pinia setup 语法，包含：

- 订单列表数据
- 搜索表单状态
- 分页配置
- 加载状态
- 业务逻辑方法

## 使用方式

1. 在路由中引入组件：

```typescript
import OrderList from '@/views/order-list/index.vue';
```

2. 在页面中使用：

```vue
<template>
  <OrderList />
</template>
```

## API 接口

当前使用模拟数据，实际使用时需要替换 `api.ts` 中的 `getOrderList` 方法为真实的 API 调用。
