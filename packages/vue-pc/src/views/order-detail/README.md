# 订单详情页面

## 功能概述

订单详情页面用于展示具体订单的详细信息，包含订单基本信息、企业信息、营业执照、经办人信息、投保模式、支付方式等完整信息。基于需求规范实现字段的显示状态控制。

## 文件结构

```
order-detail/
├── index.vue              # 主详情页面
├── store.ts               # Pinia 状态管理
├── api.ts                 # API 接口定义
├── types.ts               # TypeScript 类型定义
└── README.md              # 说明文档
```

## 页面结构

### 1. 页面头部

- 返回按钮：点击返回上一页
- 页面标题："详情"

### 2. 订单信息卡片

- **公司信息**：企业头像 + 企业名称（回显，不可修改）
- **总计保费**：右上角显示订单总保费（回显，不可修改，当子订单录入、取消、加入、清单上传、生效日期修改，需要重新计算合保费进行展示）
- **订单元数据**：
  - 团订单状态（回显，不可修改）
  - 团订单号（回显，不可修改）
  - 商品名称（回显，不可修改）
  - 销售方案编码（回显，不可修改）
  - 销售方案状态（回显，不可修改）
  - 投保日期（回显，不可修改，格式YYYY-MM-DD，投保日期=开发期开始时间）
  - 缴费方式（回显，不可修改）
  - 创建日期（回显，不可修改）
  - 保险期限（生效时间 + 产品保险期限-1天，显示总天数）

### 3. 详情标签页

#### 详情 Tab

包含以下信息组：

**企业信息**

- 企业名称
- 统一社会信用代码
- 所属行业
- 详细地址
- 注册省市区

**营业执照**

- 营业执照图片展示
- 上传/删除功能

**经办人信息**

- 经办人姓名
- 经办人身份证号
- 经办人邮箱
- 经办人手机号

**投保模式**

- 显示投保模式标签

**支付方式**

- 显示支付方式（单个方式）

**开放期设置**

- 开始时间
- 缴费时间
- 生效时间

**销售人员信息**

- 姓名
- 工号

#### 人员清单 Tab

- 导出清单按钮
- 人员列表（待实现）

## 数据字段规范

根据需求规范，以下字段均为"回显，不可修改"状态：

- 企业名称
- 总计保费
- 团订单状态
- 团订单号
- 商品名称
- 销售方案编码
- 销售方案状态
- 投保日期
- 缴费方式
- 保险期限
- 创建日期

## 技术实现

### 1. 技术栈

- **Vue 3** - 使用 Composition API
- **TypeScript** - 类型安全
- **Ant Design Vue** - UI 组件库
- **Pinia** - 状态管理（setup 语法）
- **Vue Router** - 路由导航

### 2. 数据结构

- **OrderDetail** - 订单详情主要信息
- **PersonnelItem** - 人员清单项
- **OrderDetailResponse** - API 响应结构

### 3. 状态管理

使用 Pinia setup 语法，包含：

- 订单详情数据
- 人员清单数据
- 加载状态
- 业务逻辑方法

## 使用方式

### 路由配置

```typescript
{
  path: '/order/detail/:id',
  name: 'OrderDetail',
  component: () => import('@/views/order-detail/index.vue')
}
```

### 页面跳转

```typescript
// 从订单列表跳转
router.push(`/order/detail/${orderId}`);

// 或使用路由参数
router.push({
  name: 'OrderDetail',
  params: { id: orderId },
});
```

## API 接口

### 订单详情接口

- `getOrderDetail(orderId)` - 获取订单详情数据
- `exportPersonnelList(orderId)` - 导出人员清单

### 接口特点

- 使用项目统一的 httpInstance
- 直接返回数据，无 success 包装
- 完善的 Mock 数据支持
- 符合项目 API 规范

## 扩展功能
